# 📊 Amazon Sales Analysis Dashboard

## 🚀 Overview

This project presents an analysis of Amazon e-commerce sales data using SQL, Python (Jupyter Notebook), and Power BI.

The objective is to understand customer behavior, product performance, and overall business trends through interactive dashboards.

---

## 🔄 Project Workflow

1. Data Source → Excel dataset
2. Data Analysis → SQL queries & Python Notebook
3. Data Visualization → Power BI Dashboard

---

## 📊 Key Metrics

* Total Revenue: 90.50M+
* Total Orders: 2K+
* Retention Rate: 93.32%
* Gross Profit: 39.67M
* Cancellation Rate: 10.65%

---

## 📌 Key Insights

* Gujarat and Maharashtra generate the highest revenue
* Clothing category has higher return rates
* Majority customers fall in lower loyalty segments
* Online payment methods dominate transactions

---

## 📊 Dashboard Sections

### Executive Dashboard

* Revenue trends (Year-over-Year)
* Sales channel performance
* Order status breakdown

### Customer Analysis

* Top customers by revenue
* Loyalty segmentation
* Revenue by state

### Product Analysis

* Revenue by category and brand
* Return reasons analysis
* Product performance tracking
